# Spring Boot Learning Project 🚀

This repository is a progressive learning project built while following the [Baeldung "Learn Spring Boot" Series](https://www.baeldung.com/spring-boot). It serves as a practical, hands-on playground to master Spring Boot concepts from basic bootstrapping to advanced production-ready features.

## 📌 Current Features
- **RESTful API:** Complete CRUD operations for a `Book` entity.
- **Persistence:** Spring Data JPA integrated with an H2 in-memory database.
- **Custom Configuration:** Custom server port configuration (`8081`).
- **Global Error Handling:** Centralized exception handling using `@ControllerAdvice` for clean HTTP responses (e.g., handling 404s for missing books).
- **Automated Testing:** Live integration tests testing the API layer using `REST Assured` and JUnit.

## 🛠️ Tech Stack
- **Java** - **Spring Boot** (Web, Data JPA)
- **H2 Database** (In-Memory)
- **Maven** (Build Tool)
